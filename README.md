# 💚 Ilera-Mi | Smart Health Assistant

Your personal AI-powered health companion for a better life.

---

Overview

**Ilera-Mi** is a modern web-based health assistant that helps users monitor their health and receive emotional support through an AI chatbot.

This project combines:
- AI-powered conversation (Gemini API)
- Mental health support tools
- Health calculators (BMI, BP, Blood Sugar)
- Clean and responsive UI

---

Features

AI Chat Support
- Real-time conversation using **Google Gemini API**
- Emotion-aware responses
- Built-in grounding exercises:
  - Breathing
  - 5-4-3-2-1 sensory method
  - Body awareness

---

Health Tools
- BMI Calculator with advice
- Blood Pressure checker
- Blood Sugar analysis
- Personalized health suggestions

---

### 🎨 User Experience
- Smooth typing animation (like ChatGPT)
- Stop button to control AI response
- Mobile responsive design
- Clean and calming UI (health-focused theme)
